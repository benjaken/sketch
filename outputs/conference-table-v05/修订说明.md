# V05 折角可见性修订

## 触发
用户在桌脚近景图上用红线标出折缝位置，指出桌脚应有“红线那样的折角”。

## 检查结论
折角几何在 V04 已经存在，并没有被圆化成弧面：

- 外侧折点 (1245, 483.1) mm，内侧折点 (1175, 446.9) mm，折线全长 1004 mm。
- 折线二面角实测 57.0°（外侧）/ 56.7°（内侧），且该边未被柔化（`soft=false`）。
- 端面 R23 圆角是沿 Y 向收进，折角处在空间上仍是硬折，只是端部 23 mm 内折点随之略向内偏移。

问题出在出图：V04 的样式与 8 个场景把边线显示关掉了（`EdgeDisplayMode=0`），折角只剩一片同材质的明暗过渡，在近景图里就看成“圆滑过渡”。对比见 `折角对比.png`。

## 本版改动
只改显示，不动几何：

1. 样式与 8 个场景打开边线（`EdgeDisplayMode=1`），关闭轮廓线加粗（`DrawSilhouettes=false`）。
2. 八个场景的相机按 V04 原始参数重新写入，场景顺序、名称、05 场景的装饰盖板隐藏状态保持不变。
3. 重新导出八张视图与灰模校对图；`validation.json` 重新计算。

## 校验
- 总体包围尺寸 3200 × 1390 × 775 mm，未变。
- 28 个末级零件全部为闭合实体，未变。
- 左右支脚体积均 67216887 mm³，与 V04 完全一致，说明几何未被改动。
- V04 文件保留未覆盖：`outputs/conference-table-v04/conference-table-3200x1390x775-v04.skp`。

## 复现
几何仍由 `work/conference-table/build_table_v04.rb` 生成；V05 的显示差异等价于：

```ruby
ro = Sketchup.active_model.rendering_options
ro['EdgeDisplayMode'] = 1
ro['DrawSilhouettes'] = false
Sketchup.active_model.styles.update_selected_style
Sketchup.active_model.pages.each(&:update)   # 需先逐场景设好相机
```

## 待用户确认
若仍觉得折角不够锐，可改的是端面圆角 R23：降到 R8 的试验图见 `端面圆角对比-R23-R8.png`（左：参考照片，中：R23 现有，右：R8 试验）。该改动会改变体积与端面观感，本版未提交。
